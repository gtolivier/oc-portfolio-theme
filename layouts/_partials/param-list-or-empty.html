{{- /* A front matter parameter, the key of the params map, that must be a list: the value as it is when it is one; an empty list when the key is omitted, which the caller's len or range would choke on; or else an empty list, after raising the caller's error, an empty value written for the key ('', false, 0, see is-blank-param.html) included. errorf does not stop the template: the empty list leaves the caller's part empty, so that no template execution error buries the message. */}} {{- $list := slice }} {{- if partial "is-blank-param.html" (dict "params" .params "key" .key) }}{{ errorf .error }} {{- else }} {{- $value := index .params .key }} {{- if reflect.IsSlice $value }}{{ $list = $value }} {{- else if $value }}{{ errorf .error }}{{ end }} {{- end }} {{- return $list }}
